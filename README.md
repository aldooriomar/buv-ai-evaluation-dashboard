# BUV AI Evaluation Dashboard

**Current Release: v2.0.0**

The BUV AI Evaluation Dashboard is a guided governance and evaluation platform for reviewing AI services and AI use cases at British University Vietnam (BUV).

It helps users move through a clear decision process covering:

- purpose and use case
- information and personal-data sensitivity
- impact on people or academic outcomes
- AI integration and autonomy
- GREEN / AMBER / RED governance routing
- Research Confidentiality
- Safe Exploration
- evidence and specialist review
- institutional decision
- AI Services Register status
- lifecycle review and reassessment

## Download and Run

For normal users, use the packaged release rather than the source files.

1. Open **Releases** on this GitHub repository.
2. Download `BUV_AI_Dashboard_v2_FINAL.zip`.
3. Right-click the ZIP and select **Extract All**.
4. Open the extracted folder.
5. Double-click `RUN_BUV_AI_DASHBOARD.bat`.

The dashboard runs locally and opens in the normal web browser.

No administrator rights are normally required.

## Important Governance Principle

The dashboard supports routing, evidence gathering and governance decisions.

A GREEN, AMBER or RED colour is a governance pathway indicator. It is **not by itself an institutional approval decision**.

Academic, privacy/legal, research ethics, cybersecurity, procurement and institutional decision authority remain with the appropriate authorised BUV functions.

## Data

The local evaluation backend is:

`data/BUV_AI_Evaluation_Backend.xlsx`

Each downloaded copy maintains its own local records.

Do not commit live evaluation records, confidential assessment evidence, personal information, operational logs or backup files to this public repository.

## Technology

The platform uses:

- Python local application backend

- local diagnostic and audit logging
